# 主界面成长倾向生成规则

## 目标

统一主界面人生摘要中的 `倾向` 字段生成逻辑，确保不同实现分支对“当前角色最突出的成长方向”使用一致的提取方式与展示格式。

## 设计原则

- 倾向字段服务于玩家快速理解角色发展重心
- 首页只显示 `1~2` 个最有代表性的方向
- 倾向是结论，不是完整属性报告

## 推荐字段来源

优先从以下属性中选取：

- `comprehension` 悟性
- `chivalry` 侠义
- `knowledge` 学识
- `network` 人脉
- `reputation` 声望
- `power` 功力
- `internal` 内功
- `external` 外功
- `lightness` 轻功

## 生成规则

### 规则 1：只选最能代表当前成长形态的 1~2 项

- 默认最多展示 2 项
- 如果最高项与第二项差距明显，可只展示 1 项

### 规则 2：优先选择“玩家能据此调整下一步”的属性

- 不优先展示冷门低影响属性
- 不为了凑数展示两个意义接近的属性

### 规则 3：同一组高度相近时，优先保留更能解释路线的属性

优先级建议：

1. 能解释当前玩法分支的属性
2. 能解释当前事件倾向的属性
3. 仅用于补足画面的属性

## 首页展示格式

推荐格式：

```text
倾向：悟性 24 / 侠义 13
```

或：

```text
倾向：内功 32
```

规则：

- 统一用 `属性名 + 空格 + 数值`
- 两项之间用 `/`
- 不附带解释句

## 选择边界

以下情况不建议作为首页倾向：

- 数值虽高但对当前玩法无判断价值
- 多个数值都低且没有明显代表项
- 只会增加噪音的辅助属性

若没有明显倾向，可退化为：

```text
倾向：尚未成势
```

## 文案规则

首页倾向字段只允许以下两种形式：

1. `属性名 + 数值`
2. `尚未成势`

不允许：

- 长解释
- 多于两项并列
- 带感叹或风味修辞

## 后续建议

如果未来要做自动化摘要生成，建议补：

1. 倾向候选属性权重表
2. 同分/近分裁决规则
3. 特殊流派覆盖规则

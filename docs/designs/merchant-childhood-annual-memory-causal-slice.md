# 商贾童年“年度记忆—家人认可”最小因果样板

**状态：** 已批准设计，待实施计划  
**日期：** 2026-07-17  
**范围：** 商贾出身 0～7 岁单样板

## 1. 设计目的

本样板不负责证明“整个童年已经好玩”，只验证一个可证伪假设：

> 玩家看到童年行为被家人记住，并在几年后因此第一次获得认可，是否会产生惊喜、归属感和继续游玩的欲望？

童年只是试验场。真正要验证的是一条可用于全生命周期的因果体验：

```text
环境塑造
  → 年龄合理的选择
  → 即时情绪反馈
  → 时间快速推进
  → 数值与记忆共同改变后续结果
  → 获得认可和新机会
```

## 2. 核心体验原则

### 2.1 从出生开始，不等于从出生开始逐回合规划

- 0～3 岁以见证、依恋、好奇和环境塑造为主。
- 4 岁提供第一次儿童化选择，不提供成人式职业规划。
- 6 岁回收4岁选择，让玩家第一次感到“过去的我被记住了”。
- 7 岁后接回现有商贾成长链。

### 2.2 核心奖励是“被看见”，不是“数值暴涨”

强反馈必须先由人物关系和叙事表达，再补充数值与机会说明。玩家首先应记住家人的态度变化，而不是 `经营 +1`。

### 2.3 数值必须被消费

本样板中的数值不能只负责上涨和展示，必须直接决定6岁事件的结果强度。具体记忆 flag 负责说明“为什么发生”，属性门槛负责说明“能力是否足够”。

## 3. 体验流程

### 3.1 0～3 岁：年度记忆片段

每次推进跨过一年，只显示一张年度记忆卡。每张卡包含2～3个彼此相关的生活节点，但只需要一次操作。

建议骨架：

| 年龄 | 作用 |
| --- | --- |
| 0 岁 | 出生、家庭处境、主要照料者 |
| 1 岁 | 家庭气氛与一项可感知变化 |
| 2 岁 | 第一次接触商贾生活，埋下人物或物件 |
| 3 岁 | 集中铺垫算盘、熟客与铺面生活 |

年度记忆不是全年流水账，而是角色后来仍可能记得的代表性片段。

商贾3岁示例：

> 这一年，你常跟着母亲去铺子。春天，你记住了几个熟客的称呼；入秋后，一支商队迟迟未归，父亲连续几夜睡在柜台后。年末，他把一把缺了珠子的旧算盘丢给你当玩具，你却总爱照着大人的样子拨来拨去。

### 3.2 4 岁：第一次儿童化选择

只提供两个都合理、都能获得后续回响的选项：

| 选择 | 即时变化 | 记忆含义 |
| --- | --- | --- |
| 蹲在柜边拨算盘 | `businessAcumen 4 → 5`，记录算盘记忆 | 对数字和账目自然好奇 |
| 跟着伙计招呼熟客 | `connections 2 → 3`，记录熟客记忆 | 对人和称呼自然敏感 |

选项文案不得出现“刻苦经商”“规划商路”等成人化意图，也不得把其中一个写成明显的正确答案。

选择后只给轻微即时反应，例如：

> 父亲看了你一眼，笑道：“你倒真喜欢这些珠子。”

### 3.3 6 岁：家人认可回响

同一个铺面小状况根据4岁选择产生不同结果：

#### 算盘分支

- 进入条件：算盘记忆存在。
- 结果：孩子发现账上少记一包货。
- 认可：父亲第一次认真确认孩子识数、细心。
- 新机会：允许以后跟着账房认账。
- 强度：`businessAcumen = 5` 时需要长辈提示后说清问题；`businessAcumen >= 6` 时可独立指出问题，获得更强认可。

参考表达：

> 父亲重新拨了一遍算盘，愣了片刻，把你抱到柜台后的高凳上：“以后清点时，你也坐在这里。”

#### 熟客分支

- 进入条件：熟客记忆存在。
- 结果：孩子认出熟客或记起其习惯，避免一次招待疏漏。
- 认可：家人第一次确认孩子记人、懂人情。
- 新机会：允许以后跟着长辈迎客认人。
- 强度：`connections = 3` 时在伙计提醒后想起关键信息；`connections >= 4` 时可主动认出熟客，获得更强认可。

#### 数值与记忆的职责

记忆 flag 决定6岁回响的方向，数值决定同一方向内的认可强度。4岁选择保证基础认可可达；0～3岁环境塑造或其他既有变化若让对应数值更高，则升级为独立完成和更强认可。这样不增加失败兜底，也避免属性门槛只是重复验证 flag。

### 3.4 7 岁以后：接回现有商贾成长链

6岁结果只提供一个可追踪的新机会，不新建职业、技能或路线系统。后续继续使用现有 `businessHabit`、`merchant_childhood_seed_milestone` 和商路分岔能力。

## 4. 年度记忆内容规则

每张年度记忆卡至少完成以下两项：

- 展现家庭关系；
- 展现商贾出身环境；
- 让角色发生一项微小变化；
- 种下或回收一个未来钩子；
- 推进一项已有矛盾。

强制约束：

- 一年只占一次操作。
- 一张卡包含2～3个相关节点，不拆成多张点击卡。
- 一个年度最多汇总一次数值变化，不为每句话分别发奖励。
- 平静年份可以存在，但必须留下可记忆的新信息。
- 若一句话删除后不影响人物、关系、世界或未来，应删除该句。
- 禁止“平静度日”“又长大了一岁”等纯占位文本。
- 禁止为了填满年份而制造连续灾难或成人级责任。

## 5. 技术边界

现有系统已经支持本样板所需能力：

- 被动童年叙事与年度汇总展示；
- 被动叙事设置 flag、改变小幅属性；
- 属性和 flag 条件；
- 选择后的即时反馈；
- 条件化后续事件；
- 现有商贾7岁以后成长链。

因此本样板不得新增：

- 新属性；
- 家庭关系数值系统；
- 新事件格式；
- 通用事件链框架；
- 年度事件数组或新叙事容器；
- 奖励系统；
- 技能系统；
- 其他出身的平行内容；
- 全生命周期数值重构。

若实施时发现必须修改通用事件架构、成年路线或多个无关模块，应停止实施并重新评估设计，而不是扩大范围。

## 6. 时间节奏

- 0～3 岁：被动推进由季度级压缩为年度级。
- 0～4 岁总操作数目标：不超过5次确认加1次选择。
- 第一次儿童化选择目标：开局后90秒内出现。
- 第一次跨年龄认可目标：开局后3分钟内出现。
- 4岁选择后应快速抵达6岁回响，不恢复季度级填充。
- 6岁以后恢复现有阶段节奏并接回商贾成长链。

本次只做最小的年龄段推进调整，不制作自动播放蒙太奇、播放速度设置或跳过按钮。

## 7. 验收

### 7.1 自动机制验收

1. 0～3 岁每次推进一年，每年只需要一次操作。
2. 商贾出身4岁出现两个选项。
3. 两个选项分别改变对应属性并记录具体记忆。
4. 6岁根据记忆进入算盘或熟客回响。
5. 同一记忆分支内，基础数值与高数值产生不同认可强度。
6. 两个分支分别打开对应后续机会。
7. 7岁后仍可进入现有商贾成长链。
8. 相同起点选择不同选项时，6岁叙事和新机会必须不同。
9. 不新增事件格式、属性、关系系统或通用框架。

### 7.2 人工内容审查

1. 每个年度片段包含至少两个有效生活节点。
2. 每个片段至少满足家庭关系、出身环境、微小变化、未来钩子、已有矛盾中的两项。
3. 4岁两个选项都符合儿童认知，且没有明显正确答案。
4. 6岁反馈先表达家人态度变化，再展示数值或机会说明。
5. 文本中不存在纯占位句、连续灾难或儿童承担成人责任的内容。

## 8. 真人体验验收

至少邀请3名玩家分别完成一次三分钟样板，结束后询问：

1. 为什么6岁时家人会那样评价你？
2. 4岁的选择是否真的影响了后来？
3. 是否想继续看看家人接下来会让你做什么？
4. 是否想尝试另一个4岁选项？

最低通过线：

- 至少2/3玩家能准确复述“4岁行为 → 6岁认可”。
- 至少2/3玩家明确想继续。
- 至少1名玩家主动产生尝试另一选项的意愿。
- 玩家能表达“被记住、被认可、过去行为有用”等感受，而不只是“数值涨了”。

自动测试通过不能替代真人体验结论。

## 9. 失败与止损

出现以下任一结果时，不扩展到其他出身：

- 玩家认为只是换了一段文案。
- 玩家只关注哪个选项加的数值更多。
- 玩家看不出4岁与6岁的因果。
- 年度片段仍被评价为冗长或流水账。
- 90秒内无法抵达第一次选择。
- 三分钟内无法看到第一次认可回响。
- 实施依赖通用架构重构。

失败后只回到因果表达、年度信息密度或奖励节奏做复盘，不批量扩写童年事件。

## 10. 非目标与后续边界

本样板成功只证明“年度记忆 + 儿童化选择 + 跨年龄认可”值得继续验证，不代表：

- 整个童年体验已经收口；
- 所有属性已经有意义；
- 所有出身都应复制商贾模板；
- 可以立即扩展成年路线或成就目录；
- 产品已经达到好玩或可发布标准。

只有真人体验达到最低通过线后，才讨论第二个出身样板或更广泛的数值消费审计。

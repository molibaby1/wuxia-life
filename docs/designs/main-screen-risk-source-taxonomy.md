# 主界面风险来源归类表

## 目标

统一主界面 `风险` 字段背后的来源分类，帮助后续摘要生成、事件反馈与页面呈现都围绕同一套风险语义收敛。

## 一级分类

### 1. 生存风险

- 示例：重伤、久病、断粮、极度疲弱
- 首页优先级：最高
- 典型短句：
  - `身子正虚`
  - `命数堪忧`
  - `后劲不足`

### 2. 主线推进风险

- 示例：关键条件不足、当前阶段卡死、核心机会错失
- 首页优先级：高
- 典型短句：
  - `前路受阻`
  - `时机将失`
  - `难再推进`

### 3. 身份与门派风险

- 示例：门内处境不稳、身份摇摆、地位受损
- 首页优先级：高
- 典型短句：
  - `门内不稳`
  - `立场受疑`
  - `根基未固`

### 4. 资源风险

- 示例：银两不足、物资吃紧、恢复资源不足
- 首页优先级：中高
- 典型短句：
  - `银钱吃紧`
  - `囊中见底`
  - `补给不足`

### 5. 人际与风评风险

- 示例：风评受损、人脉断裂、关键关系恶化
- 首页优先级：中
- 典型短句：
  - `风评受损`
  - `四面树敌`
  - `人情渐冷`

### 6. 成长节奏风险

- 示例：成长失衡、短板过重、学习收益太低
- 首页优先级：中低
- 典型短句：
  - `根基偏薄`
  - `进境缓慢`
  - `短板过重`

## 首页选取规则

当多个风险并存时，首页只取一个主风险，按以下逻辑筛选：

1. 先看是否影响生存
2. 再看是否阻塞下一步主循环
3. 再看是否影响当前身份/门派位置
4. 再看资源是否已进入危险区
5. 最后考虑人际与一般成长节奏

## 使用规则

- 首页风险只反映“当前最该优先处理的问题”
- 其他风险进入详情层或事件文案补充
- 不将所有风险并列堆到首页

## 后续建议

如需自动生成风险摘要，建议补一份：

- 风险来源到风险等级的映射表

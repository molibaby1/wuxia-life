# 主界面验收检查表

## 目标

为主界面改版提供统一验收清单，确保设计目标、前端实现与最终体验一致。

## 结构验收

- [ ] 顶部状态条已压缩
- [ ] 当前事件卡位于顶部状态条之后
- [ ] `继续` 按钮首屏完整可见
- [ ] 首页默认态无重复属性区
- [ ] 人生摘要卡位于事件卡之后
- [ ] 核心属性卡为 `2 x 3` 栅格
- [ ] 完整属性说明默认不在首页展开

## 信息层级验收

- [ ] 首页第一信息是当前事件
- [ ] 首页第二判断是风险
- [ ] 路线与倾向只作为摘要补充
- [ ] 首页属性区只显示名称和值
- [ ] 首页默认态不存在属性长解释
- [ ] 首页默认态不存在风味描述句堆叠

## 按钮层级验收

- [ ] `继续` 是唯一主按钮
- [ ] `人生摘要` / `全部属性` 为次按钮
- [ ] `保存` 为弱按钮
- [ ] 页面不存在两个同权重主操作

## 交互验收

- [ ] 点击 `继续` 可推进主循环
- [ ] 点击 `全部属性` 可打开详情层
- [ ] 详情层可切换分组
- [ ] 详情层关闭后回到首页默认态

## 适配验收

- [ ] H5 窄屏下首屏结构稳定
- [ ] 小程序安全区下首屏结构稳定
- [ ] 顶部与底部无遮挡
- [ ] 按钮热区不小于 `36~40`
- [ ] 长文案与长标签不会挤坏布局

## 体验验收

- [ ] 玩家可在 3 秒内看懂当前发生了什么
- [ ] 玩家可在 3 秒内判断当前风险
- [ ] 玩家可在 3 秒内找到下一步操作
- [ ] 页面默认态不再像属性百科首页

# 幼年开局体验优化方案（Agency + 开场节奏）

**状态：** 待审批（体验治理用，非实现指令）  
**来源：** `docs/test-reports/api-browser-playtest-experience-2026-06-17.md` + 体验者补充反馈  
**关联设计：** `docs/designs/p16-stage-agency-rules.md`、`docs/PRD/p16-wuxia-origin-driven-growth-and-composite-destiny.md`  
**范围：** 0～7 岁开场体验；不含少年/成年/结局线

---

## 1. 问题陈述

### 1.1 实机总评（2026-06-17）

API + 浏览器模式在 0～5 岁区间**技术可推进**，但主观耐玩度约 **★★☆☆☆**。核心痛点：

| 维度 | 现象 | 玩家感受 |
| --- | --- | --- |
| 节奏 | 约 30/35 步同一循环；占位文案「本期暂无强求的江湖变故…」高频 | 像童年日历打卡，武侠味弱 |
| 反馈 | 点「继续」时主叙事区常无文字 | 盲按、不知道发生了什么 |
| 选项 | 0～5 岁始终同一套三行动 | 无成长感、无解锁感 |
| 数值 | 0 岁首回合「玩耍练功」致侠义 +13、悟性 +11、内功 +4 | 常识断裂、信任崩塌 |
| 事件密度 | 35 步内正式剧情仅 2～3 次 | 抉择与人物感不足 |

### 1.2 体验者补充（高优先级设计缺口）

> **0 岁开始就一直有主动选择行为，但现实中的婴儿怎么可能有自主能力？婴儿时期应该几乎都是被动事件才对。**

这与已审批的 P16 Stage Agency 规则**完全一致**，但实机表现说明该规则**尚未在 API 开场路径生效**，或生效粒度不足（仅抑制了营商/游历等，未处理「每期强制三选一规划」本身）。

### 1.3 根因归纳（设计层，非实现归因）

```mermaid
flowchart LR
  A[统一「规划→继续」主循环] --> B[0岁即进入主动行动池]
  B --> C[选项文案偏学龄儿童]
  C --> D[数值 effect 按「行动」结算]
  D --> E[婴儿期像育儿策略游戏]
  F[P16 低 agency 设计] -.->|未贯通到 API 开场| B
  G[正式 spine 事件] -.->|密度过低| A
```

**一句话：** 当前开场把「全年龄通用的主动规划框架」前置到了婴儿期，与「人生由出身与环境塑形」的产品叙事冲突。

## 2. 设计目标与非目标

### 2.1 目标

1. **婴儿期（0～2 岁）以被动叙事为主**：玩家主要是「见证成长」，而非「安排人生」。
2. **幼童期（3～7 岁）逐步引入有限 agency**：偶发小选择，选项必须符合年龄与出身。
3. **与 P16 已审批 agency 表对齐**，并在体验验收中可观测。
4. **在修 agency 的同时**，保留实机报告中 P0 项（数值审计、行动小结可见性）——否则被动事件扩写后玩家仍会「盲按」。

### 2.2 非目标

- 不在本方案中规定具体代码文件或 API 字段改动方式（由实施方拆解）。
- 不重写全生命周期 pacing（见 P20）；仅聚焦 0～7 岁开场与 agency 形态。
- 不追求 0～5 岁出现大量江湖冲突；武侠感应通过**家庭/地域/异象/启蒙伏笔**建立，而非提前塞入成人江湖事件。

## 3. 目标体验：分龄 Agency 模型

在 `p16-stage-agency-rules.md` 基础上，为**开场实机问题**补充可操作的 UI/流程定义：

| 阶段 | 年龄 | 玩家操作形态 | 每期典型界面 | 主动行动池 |
| --- | --- | --- | --- | --- |
| **婴儿期** | 0～2 | **纯被动** | 单按钮「继续」或自动推进；无「规划三选一」 | **不出现** |
| **幼童前期** | 3～4 | **被动为主 + 稀抉择** | 多数期 passive；仅 spine 事件（如「童年偏好」「启蒙」）给 2～3 选项 | 不出现日常规划 |
| **幼童后期** | 5～7 | **有限主动** | 每 2～3 期最多 1 次「轻量安排」：2 选项（非 3～5 项职业向行动） | 仅出身相关的玩耍/听长辈话类，且文案婴儿化 |
| **童年晚期** | 8～12 | **受限主动** | 按 P16：training / study 可入池；营商游历等仍抑制 | 见 P16 allowlist |

### 3.1 婴儿期（0～2）内容原则

- **叙事视角**：父母、保姆、家族、环境（「你被裹在襁褓里」「抓周」「牙牙学语」）。
- **属性变化**：仅体魄/健康/微弱悟性（且幅度极小）；**禁止**侠义、内功、功力、银两在 0～2 岁因「玩家行动」跳变。
- **出身差异**：通过**不同被动事件序列**体现（书香门第 vs 边疆军户），而非让玩家在 0 岁选「听先生讲课」。

### 3.2 与现有 spine 事件的对齐

`childhoodEvents` 中已有较合理的节奏锚点，应成为主叙事骨架，而非被规划循环覆盖：

| 年龄 | 事件（参考） | 类型 | 开场中的角色 |
| --- | --- | --- | --- |
| 0 | 降生 / 异象 | 自动 | 开局第一段被动叙事 |
| 1 | 学步探索 | 自动 | 婴儿期末尾 |
| 3 | 伶牙俐齿 | 自动 | 幼童前期 |
| 4 | 童年偏好 | 抉择 | 幼童期**正式** agency 入口 |
| 6 | 武学启蒙 | 抉择 | 可选；不宜早于 4 岁偏好之后 |

**治理要点：** 在 0～2 岁，这些 spine 事件应**挤占**规划期，而不是与「三行动规划」并行存在。

## 4. 优化方案（分优先级）

### P0 — 信任与常识（必须先做）

| # | 项 | 方案要点 | 验收标准（Given / When / Then） |
| --- | --- | --- | --- |
| P0-1 | **0～2 岁禁用主动规划期** | 该年龄段 `phase` 不进入「选行动」；仅 passive / story_automatic / 单继续 | Given 角色 0～2 岁，When 连续推进 10 期，Then **0 次**出现「听先生讲课/玩耍练功/与玩伴」类规划选项 |
| P0-2 | **首回合数值审计** | 审计童年行动 effect；0 岁任何结算不得产生侠义/内功/功力跳变 | Given 0 岁书香门第，When 完成首段被动叙事，Then 侠义=0、内功=0、功力变化≤1 且有叙事说明 |
| P0-3 | **行动/事件小结可见** | 每次点「继续」前，主叙事区或专用卡片必须有本期后果文案 | Given 任意一期结束，When 玩家看到「继续」，Then 能复述「本期发生了什么、属性变了吗」 |

### P1 — 节奏与密度

| # | 项 | 方案要点 | 验收标准 |
| --- | --- | --- | --- |
| P1-1 | **降低占位规划文案占比** | 「暂无江湖变故…」在 0～7 岁应极少出现；婴儿期完全不用 | 0～5 岁实机 35 步内，该文案出现 ≤3 次 |
| P1-2 | **提高被动/spine 事件密度** | 目标：平均每 2～3 期至少 1 次非 filler 叙事（自动或抉择） | 35 步内 ≥8 条有具体情节的叙事（非空继续） |
| P1-3 | **行动池按龄分段** | 5～7 岁才出现「轻量 2 选」；8 岁起再接入 P16 allowlist | 5 岁与 1 岁选项池**不得相同** |

### P2 — 叙事与数值因果

| # | 项 | 方案要点 | 验收标准 |
| --- | --- | --- | --- |
| P2-1 | **属性变化必有叙事来源** | 侠义/悟性/银两变动须在文案中点名原因 | 随机抽 5 次属性变化，100% 可对应到叙事句 |
| P2-2 | **出身驱动被动序列** | 书香/武林/商贾/边疆在 0～7 岁至少 3 条**互斥**被动事件或变体文案 | 换出身开局，前 7 年叙事清单重合度 <50% |
| P2-3 | **武侠感铺垫** | 0～7 岁用「家族武学氛围、异象、地域险患、名侠传说」埋伏笔，而非成人江湖任务 | 实机访谈：玩家能说出「我家是练武的/读书的」但不说「我已经在闯江湖」 |

### P3 — 抛光

| # | 项 | 说明 |
| --- | --- | --- |
| P3-1 | 顶栏角色名与槽位输入一致 | 见原实机报告 |
| P3-2 | 扰动卡实机补测 | 参照 `p8-1-api-browser-acceptance-notes.md` |
| P3-3 | 操作步数压缩 | 婴儿期单点击推进；幼童期减少「选行动+继续」双点击 |

## 5. 推荐开场流程（目标态）

以下为**玩家侧**目标流程，供内容编写与验收对照：

```
【0岁】被动：降生叙事（出身决定家庭/地域描写）
  → 继续
【0～1岁】被动：抓周/多病/家族期许/边关风声…（2～4 条，出身分叉）
  → 继续（无规划）
【1～2岁】被动：学步、咿呀学语、偶发小险（自动）
  → 继续
【3岁】被动：伶牙俐齿（或出身变体）
  → 继续
【4岁】抉择：童年偏好（读书/玩耍/平衡）— 本阶段第一个「真正的选择」
  → 继续
【5～7岁】稀疏：每 2～3 期 1 次「轻量安排」或被动家庭事件；禁止每期三选一
【8岁+】进入 P16 童年晚期 allowlist + 童年总结等
```

**关键差异：** 玩家在 **4 岁** 之前应几乎从未见过「本期你可安排日常行动」界面。

## 6. 文案与选项治理（供内容微调者）

### 6.1 禁用模式（0～2 岁）

- 「听先生讲课」「玩耍练功」「与玩伴相处」作为**规划主选项**
- 任何暗示玩家自主安排人生、职业、江湖路线的文案
- 占位句「本期暂无强求的江湖变故，你可安排日常行动」

### 6.2 推荐被动文案方向（示例，非终稿）

| 出身 | 0～2 岁被动主题 |
| --- | --- |
| 书香门第 | 襁褓中听父亲诵诗、母亲描红、家中藏书气味 |
| 武林世家 | 木人桩影、长辈抱你看招、筋骨初练（**非**玩家主动练功） |
| 商贾之家 | 账房声、市井喧闹、管家逗弄 |
| 边疆军户 | 营寨号声、风沙、父亲铠甲冰冷 |

### 6.3 5～7 岁「轻量安排」示例（2 选，非三行动）

- 「今日随母亲娘家门探亲」 / 「留在家中听祖父讲古」
- 「雨后泥地玩耍」 / 「在廊下看兄长练桩」

选项后果以**微弱倾向 flag** 为主，不做大幅数值跳变。

## 7. 风险与缓解

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 被动期过长导致无聊 | 0～2 岁若只有「继续」可能更枯燥 | 控制每期文案信息量；2～3 期必有一条小情节；出身分叉提高重玩价值 |
| 与本地模式节奏不一致 | P7 PRD 已记录本地/API 节奏分叉 | 以 API 权威路径为准做验收；本地模式另列对齐 backlog |
| P16 规则已写但未落地 | 实机证明 gap | 将 P0-1 纳入 playability / API 浏览器验收 checklist |
| 只改 agency 不改反馈 | 被动事件仍可能「空白继续」 | P0-3 与 agency 改造同批交付 |

## 8. 实施建议（给微调者与开发者）

建议按以下顺序派工，**不要**在 P0 未完成时大规模扩写童年剧情：

1. **P0-1 + P0-2 + P0-3**（agency 形态 + 数值 + 反馈）— 约 1 个迭代  
2. **P1-1 + P1-2**（占位文案 + spine 密度）— 内容向，可与 1 并行  
3. **P1-3 + P2-2**（分龄行动池 + 出身被动序列）  
4. **P2-1 + P2-3**（因果文案 + 武侠铺垫）  
5. **P3** 抛光与补测  

**体验复验：** 复用 `api-browser-playtest-experience-2026-06-17.md` §9 脚本，增加检查项：

- [ ] 0～2 岁无规划三选一  
- [ ] 4 岁前无侠义/内功因玩家操作跳变  
- [ ] 继续前叙事非空  
- [ ] 35 步内 placeholder 文案 ≤3 次

## 9. 结论

| 问题 | 判定 |
| --- | --- |
| 婴儿期不应有自主规划 | ✅ 与 P16 一致；实机未达标，应升为 **P0** |
| 实机不好玩 | ⚠️ 主因是「错误 agency 形态 + 弱反馈 + 低密度 spine」，而非技术不可玩 |
| 数值不合理 | ❌ 0 岁首回合需数据层治理 |
| 既有设计是否够用 | ✅ `p16-stage-agency-rules.md` 已覆盖方向；缺的是**开场流程与 API 路径贯通** |

**治理决策建议：** 将「婴儿期被动化」与「首回合数值审计」「继续前必有叙事」捆绑为同一体验里程碑；通过后再扩写 0～7 岁事件库，避免在错误循环上堆内容。

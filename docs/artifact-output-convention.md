# Artifact and Output Convention

This project distinguishes source assets from generated runtime artifacts.

## Generated Outputs (Do Not Commit)

- `public/reports/*.html`
- `public/reports/*.json`
- `artifacts/gates/*` — P8/P11 gate runs and stage isolation proof markdown
- `artifacts/reports/*` — other script/test execution reports (JSON/Markdown proofs, inventories, diagnostics)

These files are generated by simulation and verification workflows. They are volatile and should not be committed.

**Do not** write generated run output under `docs/` (including `docs/test-reports/`).

## Tracked Fixtures (Do Commit)

- `tests/fixtures/gates/p8-playability-gate-latest.json` — P8 playability baseline consumed by P9 / regression readers

Regenerate via `npm run gate:playability`, then intentionally refresh the fixture only when the baseline is meant to move.

## Tracked Output Index

- `public/reports/manifest.json`

`manifest.json` is the only tracked report artifact under `public/reports` and acts as a stable index for report discovery.

## Rule of Thumb

If an output can be deterministically regenerated from source and scripts, treat it as an artifact and keep it out of source control unless explicitly designated as a tracked fixture.

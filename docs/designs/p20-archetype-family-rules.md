# P20 Representative Archetype Family Rules (US-004)

| ID | Label | Lifecycle distinguishing inputs |

## Material Distinction Requirements

Each family must be scoreable from **≥3 lifecycle dimensions** simultaneously:

1. Origin tags or P16 origin surface id
2. Growth flags (training/study/business/social action history)
3. Route identity keys (P11 route definitions)
4. Social role flags (P17 relationship/faction patterns)
5. Legacy shape flags (P18 successor/channel/outcome)
6. Endgame memory kind (P19 category/memory tone)

Archetype emergence must **not** reduce to a single route label or late summary line.

## Explicitly Deferred Beyond P20

- Full 8-persona P8 roster as distinct archetype families (balanced everyman stays regression baseline, not P20 tuning target)
- Cross-theme replayability (non-wuxia worlds)
- UI-facing archetype picker or run history dashboard
- Procedural origin generation beyond existing P16 surfaces
- Multi-generational dynasty play as a first-class archetype

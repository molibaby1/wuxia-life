# P7 Self-Awareness Visibility Rules (US-020)

## Scale

Self-awareness 0–100, default derived from `comprehension + 20` (capped).

| Band | Range | Implicit attribute display |
| --- | --- | --- |
| low | 0–39 | Fuzzy narrative only |
| medium | 40–69 | Fuzzy + approximate band |
| high | 70–100 | Precise numeric value |

## Explicit vs impressionistic

**Already have explicit evidence**

- P8 playability gate (8 personas, age 0–40 survival/readability)
- P12 profile section completeness
- P20 archetype regression matrix and replay slice validations
- P21 content constraint + production matrix
- P22 library coverage matrix and weak-spot detection

**Still depend mainly on impressionistic judgment**

- Whether a run "feels" meaningfully different beyond route labels
- Whether mid-life consequences carry emotional weight vs checklist flags
- Whether endgame prose and historical memory land as aftertaste vs category match
- Whether a content wave improved experience vs only expanded pools

## Main risks: gates pass without experience improvement

1. **Volume masking** — P22 pool counts can rise while weak archetype bands stay thin in player-facing moments.
2. **Route-label homogenization** — scheduling passes while summary/route readability diverges little.
3. **Late-life under-measurement** — playability gate stops at age 40; legacy/endgame acceptance is thinner.
4. **Tuning without comparison** — P21/P22 tuning samples exist but lack unified experience-acceptance baselines.
5. **Strong-dimension regression** — improving weak pools may crowd already-strong pacing without explicit guard.

## P23 targets

- Unify scattered surfaces under explicit experience dimensions and baselines.
- Add wave-to-wave comparison that separates "more content" from "better lives."
- Wire long-term balance indicators for sustained tuning review.

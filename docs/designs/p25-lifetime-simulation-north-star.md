# P25 武侠一生模拟 — 最终目标（North Star）

本文档定义 P25 及后续 Discovery 外层环所对照的**最终玩家体验目标**。它是产品真值的叙述层补充；可验收口径以 `docs/PRD/p25-wuxia-lifetime-simulation-experience.md` 的 Goals 为准。

## 1. 一句话愿景

玩家能在**当前武侠世界观**中，完整模拟「一个人从出生到终局的一生」——既有清晰可追的成就路径，又有足够的随机与意外让每次重开都值得；最高成就必须**运气与选择共同成立**，而平凡出身也能讲出可信、显著、不自相矛盾的故事。

## 2. 核心体验循环

```text
出身与时代底色
  → 被动经历 + 事件触发选择 + 主动规划
  → 即时反馈 + 中期后果 + 远期回响
  → 阶段性目标（主流 / 混合 / 巅峰成就）
  → 终局总结与重开动机
```

玩家每一轮都应同时感受到：

| 维度 | 玩家心理 |
| --- | --- |
| **可达性** | 我清楚自己在朝什么方向成长，努力有回报 |
| **不确定性** | 意外事件会改写机会窗口，但不会毫无理由 |
| **重玩性** | 换出身、换路线、换风险偏好，会开出不同人生 |
| **可信性** | 后果与先前选择、关系、资源、声望一致，无逻辑断裂 |

### 3.2 巅峰成就（Wave 2 — 运气 + 选择双门槛）

在主流成就之上，少数**极稀有结果**（如「武林神话」「开派祖师」「改变江湖格局」）必须同时满足：

- **选择合理**：关键节点没有自相矛盾或自我毁灭式路线
- **运气足够**：至少 1 条稀有事件线或低概率窗口被触发且未被浪费
- **窗口不等人**：错过稀有窗口后，同局内不可通过纯 grind 补救

玩家应能复盘：「我差的是那一剑的机缘，不是少练了三年。」

### 3.3 混合成就（Wave 3 — 跨界组合）

鼓励「非单路线」人生，例如：

- 医武双绝、商武一体、隐世高人兼幕后棋手
- 正邪夹缝中的生存大师、劫后重建者

要求：

- 条件跨 **2 条以上身份轨道** 或 **2 条以上资源/关系维度**
- 摘要与终局能体现**复合身份**，而非仅贴多个标签
- 与 Wave 1 主流成就**可并存或互斥**，规则必须在配置层显式声明

### 3.4 平凡出身下的可信人生（Wave 4 — 出身光谱）

在现有「鲜明出身」之外，补齐**相对平凡**的起点（如：普通农户、小镇学徒、跑堂伙计、书塾子弟），并保证：

- 平凡出身**不是**「削弱版天才」，而是**不同的机会结构**
- 仍有机会达成中档主流成就或混合成就；巅峰成就概率更低但**不为零**
- 早期以**被动经历 + 少量有意义选择**为主，符合年龄感

## 4. 选择体系

### 4.1 主动选择（玩家发起）

- 人生规划、路线投入、关系经营、资源分配、风险决策
- 随年龄增长，主动选择权重**逐步上升**（与 P16 agency 规则一致）
- 每个主动选择必须产生：**即时叙事反馈 + 可见状态变化 + 至少 1 条可追踪的长期影响**

### 4.2 事件触发选择（系统发起）

- 遭遇、试炼、人情债、派系博弈、机缘、灾祸
- 选项必须**对当前状态合理**（资源、关系、年龄、路线、flags 约束）
- 拒绝/回避也是选择，应有**可观测后果**，而非静默 noop

### 4.3 选择与后果的一致性规则（硬约束）

以下情况视为**体验缺陷**，Discovery 与验收必须拦截：

| 缺陷类型 | 示例 |
| --- | --- |
| **因果断裂** | 曾杀师求道，终局仍被描述为「尊师重道」 |
| **状态幽灵** | flag 已清除，旧事件仍按旧关系触发 |
| **窗口矛盾** | 事件要求「独身」，同时强制触发「妻室线」 |
| **反馈缺失** | 关键抉择只改隐藏值，玩家看不到任何变化 |
| **无效重开** | 换出身后前 10 年事件序列高度相同且无主题差异 |

## 5. 随机与意外

随机性服务于** memorable moments**，不是纯噪声：

- **稀有事件线**：低概率、前置条件、可被出身/选择放大或缩小概率
- **意外变故**：伤病、天灾、派系清洗、贵人出现、传承断绝
- **可解释性**：模拟报告能说明「为何这次触发了 / 为何没触发」

随机不得推翻已锁定的**硬逻辑后果**（如已死亡、已叛门、已立誓）。

## 6. 重玩动机

最终版本应同时满足：

1. **目标驱动**：玩家能选定本局要追的 1–2 个成就或身份方向
2. **探索驱动**：未尝试过的出身、路线、风险偏好，会暴露新事件池或新后果链
3. **复盘驱动**：终局摘要解释「为何达成 / 为何差一步」，激发「下一局换策略」

内部指标 proxy（供 Discovery / 模拟门禁对照）：

- 多 seed 下，**不同出身 + 不同关键选择** 产生 **≥3 条 materially different** 全生命周期轨迹
- 巅峰成就达成率 **低于** 主流成就，且模拟中 **≥80%** 失败案例能归因到「缺稀有线 / 缺关键选择 / 窗口错过」之一
- 跨周目 **高价值重复事件率** 持续下降（沿用 P20 口径），但**主题回响**保留

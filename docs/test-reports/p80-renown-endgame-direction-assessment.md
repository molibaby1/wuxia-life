# P80 Renown Endgame Direction — GO/NO-GO Assessment

> **Date:** 2026-06-29
> **Stage:** P80 Wuxia Renown Endgame Design-First Contract
> **Purpose:** Assess whether renown endgame is worth doing, and if so, define its core positioning

---

## 1. Executive Summary

**Verdict: CONDITIONAL_GO — but with strict lightweight constraints**

Endgame adds meaningful narrative value for the renown route because the core theme of renown is "名声" (reputation). The transition from "活人的名声" (reputation of a living person) to "身后之名" (posthumous legacy / how the jianghu remembers you) is a natural culmination of the renown theme — something that late-life doesn't fully address.

However, this is a **conditional GO**:
- Must stay lightweight: 1 echo event + expression updates only
- Must have 3 meaningfully different variants (one per late-life branch)
- Must clearly differentiate from both late-life AND generic P19 endgame
- Must preserve tavern-born renown flavor

If any of these conditions can't be met, it should be NO-GO.

---

## 2. Late-Life Closure Assessment

### 2.1 What Late-Life Already Provides

Late-life (P79, age 52-56) already delivers:
- ✅ 3 distinct branches with clear identities
- ✅ Strong narrative closure for each path
- ✅ Stat changes that reflect late-life state
- ✅ 6 expression surfaces updated (sample line + ordinary origin)
- ✅ Tavern-born flavor consistent throughout
- ✅ Complete narrative arc: origin → bridge → on-ramp → pressure → payoff → late-life

### 2.2 What Late-Life Does NOT Address

Late-life is still an **active life stage** — the character is still "living their life." What it doesn't provide:

1. **Legacy perspective:** From "maintaining reputation" to "how will I be remembered?"
2. **Jianghu memory angle:** The renown route is about reputation — but late-life is still about *your* experience of reputation, not about *others' memory* of you
3. **Final coda feel:** Late-life feels like the last chapter of an active life; endgame should feel like the epilogue
4. **"From living legend to memory" transition:** This is the natural culmination of the renown theme

### 2.3 Closure Sufficiency Verdict

**Late-life provides strong closure, but not final closure for the renown theme specifically.**

For merchant route, late-life might be sufficient (守成已够). But for renown route — whose entire identity is built around reputation and how others see you — the transition from "living reputation" to "posthumous memory" is the natural thematic peak.

## 3. Endgame Core Positioning

### 3.1 Selected Direction: Legacy Echo (身后名之声)

**Endgame = "江湖如何记住你" 的最终回声**

Not life review. Not death scene. Not new choices.

Instead: a single echo event at age 60-65 where you realize — or hear — how the jianghu now remembers you. Your reputation has outgrown you; it's become a story people tell.

This is the natural culmination of the renown theme:
- Bridge: 你开始有了名声
- On-ramp: 声名渐起
- Pressure: 名声成了负担
- Payoff: 你选择如何了结人情债
- Late-life: 你晚年如何过
- **Endgame: 江湖如何记住你**

### 3.2 Why This Direction

| Reason | Explanation |
|--------|-------------|
| **Thematic fit** | Renown is about reputation; legacy echo is reputation's final form |
| **Differentiates from late-life** | Late-life = your experience of aging; Endgame = others' memory of you |
| **Differentiates from P19 generic endgame** | P19 = comprehensive life review + historical memory; Renown endgame = focused on reputation/jianghu memory only |
| **Lightweight compatible** | Can be done as 1 echo event + expression updates |
| **3-branch leverage** | Each late-life branch naturally leads to a different "how they remember you" |
| **Tavern-born flavor** | 酒肆里的传说、老客人们的谈论、后辈从酒肆里听来的故事 |

### 3.3 What Endgame Is NOT

- ❌ Not a new life stage with new goals
- ❌ Not a death scene
- ❌ Not a choice event (player already made all their choices)
- ❌ Not a multi-event arc
- ❌ Not a generic "回顾一生"

### 3.4 Essential Difference: Endgame vs Late-Life

| Dimension | Late-Life (52-56) | Endgame (60-65) |
|-----------|-------------------|-----------------|
| **Perspective | First-person (your life) | Third-person (jianghu's memory) |
| **Core theme** | 你晚年怎么过 | 江湖怎么记住你 |
| **Agency** | You're still living it | It's happening around you / to your legacy |
| **Tone** | Earned rest / consequence | Echo / memory / legend |
| **Relation to renown** | Maintaining or living with your reputation | Reputation outlives you |
| **Event type** | Auto (consequence) | Auto (echo / realization) |

## 4. Three Branches — Unified or Differentiated?

### 4.1 Decision: 3 Distinct Endgame Variants

**Yes, all three late-life branches need distinct endgame echoes.**

Rationale:
1. Each late-life branch has a fundamentally different identity
2. Each naturally leads to a different "how jianghu remembers you"
3. The 3-branch structure is what makes renown late-life interesting — endgame should deepen that, not flatten it
4. Lightweight constraint is still satisfied (1 event with 3 variants, not 3 separate events)

## 5. Endgame vs Generic P19 Endgame — Distinction

| Dimension | Renown Endgame (P80/81) | Generic P19 Endgame |
|-----------|--------------------------|----------------------|
| **Scope** | Route-specific (renown only) | All routes / all origins |
| **Focus** | Reputation / jianghu memory specifically | Comprehensive: relationships + factions + legacy + memory |
| **Timing** | 60-65 (echo event) | End of life / death |
| **Depth** | Single focused echo | Multi-faceted recovery + memory |
| **Flavor** | Tavern-born renown specific | Generic wuxia |
| **Purpose** | Culmination of renown theme | Final life closure |

**Key distinction:** Renown endgame is a **route-specific thematic coda**, not a generic end-of-life system. It deepens the renown route's core theme (名声/reputation).

## 6. GO / NO-GO Detailed Assessment

### 6.1 GO Criteria Check

| Criterion | Status | Notes |
|-----------|--------|-------|
| 1. Adds meaningful narrative value beyond late-life | ✅ Yes | Legacy echo = "从活人名声到身后名"的转变，是 renown 主题的自然顶峰 |
| 2. Can be done within lightweight scope | ✅ Yes | 1 echo event + expression updates = fits within constraint |
| 3. 3 late-life branches create meaningful differentiation | ✅ Yes | Each branch naturally leads to different "jianghu memory" |
| 4. Tavern-born flavor preserved and enhanced | ✅ Yes | 酒肆传说、老客人谈论、后辈听故事 — all tavern-born |
| 5. Clear distinction from late-life AND P19 | ✅ Yes | Perspective shift (first → third person); scope difference |
| 6. Implementation effort justified by narrative value | ⚠️ Conditional | Value is real but modest; lightweight constraint makes effort acceptable |

### 6.2 NO-GO Criteria Check

| Criterion | Status | Notes |
|-----------|--------|-------|
| 1. Late-life already provides sufficient closure | ❌ No | Late-life provides life closure but not thematic (reputation → legacy) closure |
| 2. Endgame would feel redundant or tacked-on | ❌ No | Not redundant if positioned as "jianghu memory" vs "your life" |
| 3. Endgame requires more than lightweight scope | ❌ No | 1 echo + expression updates fits |
| 4. 3-branch differentiation is superficial | ❌ No | Each branch has fundamentally different legacy angle |
| 5. Narrative value doesn't justify effort | ⚠️ Borderline | Value is modest but effort is also modest (lightweight) — acceptable |

### 6.3 Final Verdict

**CONDITIONAL_GO**

**Why GO:**
- Thematic fit is strong — reputation → legacy is the natural renown culmination
- 3-branch structure creates meaningful differentiation
- Can be done within lightweight constraint
- Tavern-born flavor enhances well (酒肆传说 angle)
- Late-life provides life closure but not thematic closure

**Why conditional (not full GO):**
- Narrative value is real but modest — it's a coda, not a new act
- Single origin (tavern_hand) means lower replication value
- Must strictly adhere to lightweight constraint
- If implementation starts creeping beyond 1 event + expression, stop and reconsider

## 7. Endgame Event Shape (High-Level)

- **Type:** Auto echo event (not choice)
- **Age range:** 60-65 (recommend 62±3)
- **Trigger:** age_reach + renown_late_life_done gate
- **Branching:** Based on late-life branch marker (3 variants)
- **Checkpoint:** renown_endgame_done
- **Expression updates:** Sample line (cost label + current goal + identity) + ordinary origin (current goal + life memory + summary)
- **Stats:** Minimal or none — endgame is about memory, not stat changes

## 8. Tavern-Born Flavor Anchors

Endgame must lean into tavern-born specifics:

**Branch A (油尽灯枯):**
- 老客人还会提起你，但新客人只听过传说
- 酒肆门槛还在，但人已经坐不住了
- "那个老掌柜啊，人真好……" — 但说的人也记不清细节了

**Branch B (逍遥自在):**
- 酒肆里有人说见过你，但没人知道你在哪
- 你的故事成了酒桌上的谈资
- "听说他当年……" — 真假参半的传说

**Branch C (传承授业):**
- 后辈们在酒肆里讲你的故事
- 你的智慧通过弟子们传下去
- 老掌柜的规矩、老掌柜的话 — 成了酒肆的传统

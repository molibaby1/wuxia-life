# 主界面状态与交互矩阵

## 目标

整理主界面主要模块的默认状态、触发动作、结果状态与边界情况，便于前端实现和测试对齐。

## 矩阵

| 模块 | 默认状态 | 用户动作 | 结果 | 备注 |
| --- | --- | --- | --- | --- |
| 顶部状态条 | 正常显示 | 点击保存 | 触发保存 | 保存为弱按钮 |
| 当前事件卡 | 正常显示 | 点击继续 | 推进主循环 | 首屏主操作 |
| 当前事件卡 | 文案过长 | 无 | 折叠显示 | 最多 3 行 |
| 当前事件卡 | 正常显示 | 点击人生摘要 | 跳转/滚动到摘要 | 次级入口 |
| 当前事件卡 | 正常显示 | 点击全部属性 | 打开完整属性层 | 次级入口 |
| 人生摘要卡 | 正常显示 | 无 | 只读展示 | 默认三行 |
| 核心属性卡 | 正常显示 | 点击查看完整属性说明 | 打开完整属性层 | 次级入口 |
| 完整属性层 | 默认关闭 | 点击全部属性 | 打开 | 默认不占首页空间 |
| 完整属性层 | 打开 | 切换页签 | 切换分组 | 战斗/江湖/成长/资源 |
| 完整属性层 | 打开 | 关闭 | 返回首页默认态 | 不影响继续按钮层级 |

## 边界情况

### 长事件文案

- 默认折叠到 3 行
- 不允许把 `继续` 挤到第二屏

### 长标签

- 优先裁剪低优先级标签
- 不允许顶部状态条变成双层标签墙

### 极端数值

- 数值过大时优先保证数值可读
- 不允许溢出破坏 2x3 栅格

### 风险极高

- 允许风险字段强化
- 不允许取代事件卡成为页面唯一中心

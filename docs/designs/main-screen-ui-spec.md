# 主界面 UI 设计规范表

## 目标

将主界面收敛为适合 H5 与小程序的紧凑型移动端布局，保证玩家在 3 秒内完成以下判断：

1. 这回合发生了什么
2. 当前状态是否危险
3. 下一步应该点哪里

核心原则：

- `继续` 首屏可见且是唯一主按钮
- 首页默认态只保留摘要，不展示属性百科
- 详细属性进入二级层，不阻塞主循环
- 同一属性不在首页重复出现两次

## 信息架构

首页默认态从上到下仅保留四个模块：

1. 顶部状态条
2. 当前事件卡
3. 人生摘要卡
4. 核心属性卡

完整属性说明进入折叠区或底部抽屉，默认收起。

## 页面基础规范

- 设计基准：`390 x 844`
- 页面边距：`16`
- 模块间距：`12`
- 卡片内边距：`16`
- 大卡圆角：`20`
- 中卡圆角：`16`
- 小标签 / 小按钮圆角：`12`
- 顶部内容距安全区下沿至少：`12`
- 底部主按钮区距安全区上沿至少：`12`

## 字体层级

- 页面主标题 / 关键数字：`28`
- 模块标题：`20`
- 正文：`16`
- 辅助文字：`13`
- 标签文字：`12`

规则：

- 数值字号必须大于说明字号
- 首页默认态不出现多档说明字重混用
- 说明文字不得抢过标题与主按钮

## 颜色权重

整页只保留一套暖武侠中性色体系：

- 页面底色：浅米白
- 主卡底色：暖白或极浅米色
- 次卡底色：比主卡略深半级
- 主文字：深褐
- 次文字：灰褐
- 分隔线：浅米灰
- 主按钮：深棕
- 主按钮文字：白色
- 风险提醒：赭黄或偏深金棕
- 低优先信息：淡灰褐

规则：

- 整页最多保留一个强主色块
- 深色大面积面板退出首页默认态
- 避免顶部、中段、下段使用割裂的高反差底色

## 模块规范

### 1. 顶部状态条

- 高度：`96~104`
- 第一行：角色名 / 保存
- 第二行：年龄 + 日期
- 第三行：门派标签、阶段标签
- 第四行：银两、体魄、声望

规范：

- 保存按钮高度：`36`
- 保存按钮采用轻描边或浅填充
- 标签高度：`24`
- 标签左右内边距：`10`
- 资源字段之间间距：`12~16`

### 2. 当前事件卡

- 高度建议：`190~220`
- 标题：`当前经历`
- 正文：最多 `3` 行
- 主按钮：`继续`
- 次入口：`人生摘要`、`全部属性`

规范：

- 卡片圆角：`20`
- 标题与正文间距：`8`
- 正文与按钮间距：`16`
- 主按钮高度：`50`
- 主按钮宽度：撑满卡片内容区
- 次按钮高度：`36`
- 次按钮并排展示，间距：`8`

交互规则：

- `继续` 永远是页面唯一最高权重按钮
- 事件正文超出 3 行时折叠
- 首页默认态不允许事件文案撑长页面

### 3. 人生摘要卡

- 高度建议：`120~140`
- 内容固定为三行：
  - 路线：中立门派 · 未入门
  - 风险：中 · 身子正虚
  - 倾向：悟性 24 / 侠义 13

规范：

- 每行一个主题
- 左侧主题词固定宽度
- 右侧内容自适应
- 行间距：`10`
- 不使用长段落
- 风险字段可用轻强调色，但权重低于主按钮

### 4. 核心属性卡

- 高度建议：`150~170`
- 布局：`2 行 3 列`
- 推荐字段：
  - 功力
  - 外功
  - 内功
  - 轻功
  - 体魄
  - 银两

每格内容仅保留：

- 属性名
- 当前值

规范：

- 每格最小高度：`52`
- 属性名与数值间距：`4`
- 数值字号：`28`
- 名称字号：`15`
- 不出现解释句
- 不出现进度条
- 不出现重复分组标题

底部入口：

- `查看完整属性说明`

### 5. 完整属性层

建议形式：

- 优先：底部抽屉
- 次选：页内折叠面板

结构：

- 页签：战斗 / 江湖 / 成长 / 资源
- 每项属性一行或一组

单项属性规范：

- 第一行：名称 + 值
- 第二行：一句说明
- 可选第三行：进度条，仅战斗成长类使用

尺寸：

- 行间距：`12`
- 组间距：`16`
- 页签高度：`36`
- 抽屉顶部圆角：`20`

规则：

- 详细属性说明仅在这一层展示
- 风味文案一项最多一句

## 按钮体系

整页只保留三种按钮：

### 主按钮

- 用途：`继续`
- 高度：`50`
- 圆角：`14`

### 次按钮

- 用途：人生摘要 / 全部属性 / 返回主界面
- 高度：`36`
- 圆角：`12`

### 弱按钮

- 用途：保存 / 页签 / 辅助切换
- 高度：`32~36`
- 圆角：`10~12`

规则：

- 同一屏最多一个主按钮
- 保存按钮不得与 `继续` 同权重
- 次按钮不得抢过事件卡

## 首页默认文案规则

首页默认态只允许三类文案：

1. 当前事件
2. 状态结论
3. 核心数值

移出首页的文案：

- 属性解释长句
- 风味描述句
- 重复性属性列表
- 系统式百科说明

建议文案替换：

- `展开详情` -> `全部属性`
- `收起` -> `返回主界面`
- `角色属性` -> `核心属性`
- `风险信号` -> `风险`

## 首页验收标准

改版后必须满足：

1. 首屏可看到当前事件与完整 `继续` 按钮
2. 首页默认态不再出现重复属性
3. 玩家 3 秒内能知道：
   - 发生了什么
   - 当前状态好不好
   - 下一步点哪里
4. 详细属性不阻塞主循环
5. H5 与小程序下点击热区不小于 `36~40`

## 实施优先级

- `P0`：继续按钮上移、属性详情折叠、重复区删除
- `P1`：人生摘要重写为结论型卡片
- `P2`：顶部状态条压缩
- `P3`：完整属性抽屉与页签细化

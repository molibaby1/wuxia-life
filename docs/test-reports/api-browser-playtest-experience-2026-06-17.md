## 2. 技术状态（能否推进）

### 2.1 历史问题（已修复方向）

| 现象 | 根因（已定位） | 状态 |
| --- | --- | --- |
| 自动剧情点「继续」无反应 | API 模式未调 `story_automatic`；volatile 未存 `pendingStoryEventId` | 已补链路 |
| 顶栏年龄/属性不变化 | UI 读本地 `gameEngine`，未用服务端 `player` | 已补 `player` 下发与展示 |
| 自动化长时间空转 | 规划阶段误显「继续」+ 无进展仍重试 | 已隐藏规划期继续；测试设步数上限 |

### 2.2 本轮实机结论

- **可以推进**：选出身 → 主动规划 → 选行动 → 继续 → 时间/年龄向前走。
- **典型循环**：`规划（三选一行动）→ 继续（小结/自动剧情）→ 回到规划`。
- **未观察到** 此前「1 岁卡死在边关出身叙述」的阻断（在重启 API + 前端后）。

## 3. 好不好玩（主观体感）

**总评：★★☆☆☆ — 能玩，但不耐玩。**

### 3.1 正向

- **主动规划框架清晰**：每期在若干行动中选一项，符合「自己安排人生」的设计意图。
- **出身与童年行动有呼应**：书香门第后出现「听先生讲课 / 玩耍练功 / 与玩伴相处」，逻辑自洽。
- **偶发剧情质量尚可**：如 3→4 岁「你已经能说会道……」；4 岁启蒙抉择（专心读书 / 继续玩耍 / 平衡两者）有代入感。

### 3.2 负向（影响留存）

1. **节奏单调**  
   约 30/35 步为同一循环，文案高频出现：「本期暂无强求的江湖变故，你可安排日常行动。」  
   武侠味弱，像童年日历打卡。

2. **反馈薄弱**  
   多次点「继续」时，剧情区**无文字**（行动小结未稳定呈现在主叙事区），玩家像在盲按。

3. **选项长期不变**  
   0～5 岁始终是同一套三行动，无随年龄解锁的新行为（如帮工、跑腿、拜师铺垫等）。

4. **操作负担**  
   每期常需「选行动 + 点继续」两次；中间夹杂无文案继续，节奏拖沓。

5. **与品类预期落差**  
   产品名「武侠人生」，实机前 5 年更接近「书香门第育儿模拟」，江湖冲突、人物、抉择后果感不足。

## 4. 事件是否合理

| 事件类型 | 样本 | 合理性 | 备注 |
| --- | --- | --- | --- |
| 出身四选一 | 武林世家 / 书香门第 / 商贾 / 边疆 | ✅ 合理 | 文案得体，选项清晰 |
| 童年主动行动 | 听先生讲课、玩耍练功、与玩伴 | ✅/⚠️ | 与出身匹配；0～2 岁「练功」略早但可接受 |
| 占位规划文案 | 「暂无强求的江湖变故…」 | ❌ 过频 | 像系统 filler，挤压叙事空间 |
| 自动童年叙述 | 「能说会道」「边关营寨出身」等 | ✅ 单条合理 | 密度太低，且与出身可能错位感（需查触发条件） |
| 剧情抉择 | 4 岁启蒙三选一 | ✅ 较好 | 35 步内仅 ~2～3 次正式剧情，密度不足 |
| 江湖随机事件 | — | ❌ 缺失感强 | 0～5 岁几乎未见变故、人物、冲突 |

**事件治理方向**：提高正式 `story_event` 密度；降低占位规划文案占比；童年行动池按年龄段分层。

## 5. 成长数值是否符合常识

### 5.1 首回合异常（高优先级）

**场景**：0 岁，书香门第，第一次选「玩耍练功」，点继续后：

| 属性 | 变化 | 常识判断 |
| --- | --- | --- |
| 侠义 | 0 → **13** | ❌ 婴儿玩耍不应暴涨侠义 |
| 悟性 | 10 → **21** | ❌ 单回合 +11 过猛 |
| 内功 | 0 → **4** | ❌ 1 岁内功不合理 |
| 银两 | 100 → 50 | ⚠️ 可解释为耗费，但幅度偏大 |
| 功力/外功 | 0 → 1 | ✅ 勉强可接受 |

此后 **侠义长期停在 13** 不动，说明首回合跳变像一次性异常，而非平滑成长曲线。

### 5.2 0～5 岁整体曲线

| 属性 | 约 0 岁 → 5 岁 | 评价 |
| --- | --- | --- |
| 功力 / 外功 | 0 → 6 | 偏慢，尚算温和 |
| 体魄 | 10 → 16 | 合理 |
| 悟性 | 10 → 26 | 首回合贡献过大，后期几乎不涨 |
| 轻功 | 0 → 3（某回合突跳） | ⚠️ 无叙事铺垫 |
| 银两 | 100 → 50 → … → 0（约 4 岁） | ⚠️ 变化缺少可见因果 |

**数值治理方向**：审计「玩耍练功」等童年行动的 effect 表；侠义/内功/悟性应有来源叙事或延后生效；属性变化需在行动小结/UI 中可见。

## 6. 典型一局轨迹（摘要）

```
0岁 选书香门第
 → 规划：听先生讲课 / 玩耍练功 / 与玩伴相处
 → [玩耍练功] → 继续 → 侠义/悟性异常跳变
 → 重复规划循环（时间逐月/逐季前进）
3岁 自动剧情：「能说会道…」
4岁 剧情抉择：启蒙兴趣（玩耍探索等）+ 继续
 → 回到同一套三行动规划
5岁 功力约 6，体魄约 16，银两 0
```

**步数**：35 步内无结局；无扰动卡实机样本。

## 7. 治理 backlog（建议优先级）

| P | 项 | 类型 | 验收线索 |
| --- | --- | --- | --- |
| P0 | 审计 0 岁「玩耍练功」等行动的效果配置（侠义 +13 等） | 数值 | 首回合无侠义/内功暴涨；变化可在小结看到 |

| P2 | 数值变化需有叙事来源（尤其侠义、内功、银两） | 内容+数值 | 剧情或小结点名原因 |

## 9. 复现（治理复验用）

```bash
npm run p6b:serve          # 终端 A（改后端后需重启）
npm run dev                # 终端 B，默认端口 5200
```

1. 打开 `http://localhost:5200/`
2. 空槽或覆盖开局 → 女 / 任意名 → **书香门第**
3. 连续 10 期：交替选「玩耍练功」「听先生讲课」
4. 记录：首回合属性跳变、继续时是否空白、是否出现非规划剧情
5. 推进至 ≥4 岁，确认是否出现启蒙抉择事件

若卡在连接：清浏览器 `localStorage` 中陈旧 device token 后刷新（见 `p8-1-api-browser-acceptance-notes.md`）。

## 10. 结论（给治理决策）

| 维度 | 结论 |
| --- | --- |
| 技术可推进 | ✅ 当前 API+浏览器主链路可玩通 |
| 好不好玩 | ❌ 前 5 年单调、武侠感弱、反馈差 |
| 事件合理性 | ⚠️ 单条尚可，密度与变化不足 |
| 数值常识 | ❌ 首回合存在明显异常，需数据层治理 |

**建议**：在 P8 体验治理中，将「首回合数值审计」与「行动小结可见性」置于剧情扩写之前；否则扩写后玩家仍可能在「盲按继续」中流失。

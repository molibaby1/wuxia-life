# PRD: P7.1 主动行动体验收口

## 1. 背景

P7 已经把主流程从纯随机事件驱动推进到“无强制事件时提供主动行动”的基础闭环，并通过 `build`、`test`、`gate:p5`、`gate:experience` 和 `gate:golden-line` 验证。

P7 收口报告仍留下三个体验边界：

- API 模式尚未接入主动行动。
- 39 个 deferred 事件文件中的属性分支仍不可达。
- 扰动目前主要记录在 history，并以简短标题拼进行动反馈，尚未形成轻量叙事 UI。

P7.1 不应扩散成新大系统。它只做主动行动体验收口：让玩家在本地 Web 主流程中更清楚地理解“本期做了什么、为什么发生扰动、接下来还能继续规划什么”，同时把 API 模式边界和 deferred 事件边界写清楚，避免后续误把残余风险当作已完成能力。

## 2. 核心循环

P7.1 聚焦以下闭环：

```text
玩家选择主动行动 -> 展示行动小结 -> 如有扰动则展示轻量叙事 -> 玩家确认影响 -> 回到下一期规划
```

扰动不应只是 history 里的内部记录，也不应立即扩写成完整事件链。P7.1 的目标是介于两者之间：用轻量叙事卡表达扰动的标题、文本、来源、影响和下一步回流。

## 3. 目标

1. 让主动行动结果从“一句日志”升级为可读的本期小结。
2. 为扰动提供轻量叙事展示，而不是只拼接标题。
3. 明确主动行动、扰动和剧情事件在 UI 与报告中的来源差异。
4. 给 API 模式增加明确能力边界提示，避免玩家误以为服务端模式已支持主动行动。
5. 把 39 个 deferred 事件文件保持为后续内容接线范围，不在 P7.1 批量接入。
6. 保持 P7 已通过的 `build`、`test`、`gate:p5`、`gate:experience`、`gate:golden-line` 不回归。

## 4. 非目标

- 不实现 API 模式主动行动服务端接口。
- 不修改 P6B 的服务权威模型、session API 或数据库 schema。
- 不批量接入 39 个 deferred 事件文件。
- 不扩写完整扰动事件链。
- 不新增天赋、道具、区域、势力或世界观大系统。
- 不重做整体 UI 视觉风格。
- 不放宽既有体验 gate。

## 5. 范围

### 5.1 In Scope

- 本地 Web 主流程的主动行动结果展示。
- 扰动轻量叙事模型、展示和 history/report 来源标记。
- 主动行动后的继续/回流交互。
- API 模式能力边界提示和文档化。
- P7.1 验证报告。

### 5.2 Out of Scope

- 后端主动行动 API。
- deferred 事件文件接线。
- 完整事件编辑器或内容生产管线。
- 新经济、背包、装备或天赋系统。

## 7. 验收门禁

P7.1 每个实现 story 至少需要：

- TypeScript 类型检查或构建通过。
- 涉及 UI 的 story 必须本地浏览器验证。
- 涉及报告的 story 必须生成可复现报告。
- 不修改 API 服务端 schema 或 P6B contract。
- 不接入 deferred 事件文件。

P7.1 收口必须通过：

- `npm run build`
- `npm test`
- `npm run gate:p5`
- `npm run gate:experience`
- `npm run gate:golden-line`

## 8. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 扰动 UI 扩散成完整事件链 | 范围失控 | 只做轻量叙事卡，不新增事件链状态机 |
| API 模式误导玩家 | 服务端模式体验断裂 | 明确提示 API 模式暂不支持主动行动 |
| deferred 文件被顺手接入 | 引入大量内容和条件风险 | P7.1 明确禁止批量接线 |
| 本期小结变成信息噪音 | 玩家阅读负担增加 | 只展示行动、时间、关键影响和下一步 |
| 体验 gate 回归 | P7 已稳定能力受损 | 每波实现后复跑相关 gate |

## 9. 实施顺序

1. 先完成 US-001 到 US-003，冻结现状和边界。
2. 再完成 US-004 到 US-006，收口主动行动小结。
3. 再完成 US-007 到 US-011，收口扰动轻量叙事。
4. 再完成 US-012 到 US-014，补齐来源标记和报告。
5. 最后完成 US-015 到 US-017，进行浏览器和全量门禁验证。

每个 story 单独实施、单独验证、单独记录结果。若发现必须实现 API 主动行动或批量接入 deferred 事件，停止当前 story，另起后续 PRD。

# P8 Human Test Slice — Admission Scope

> **P8.1 更新：** API 模式验收见 `docs/designs/p8-1-api-human-slice.md`。下文「本地 Web 切片」仅作历史参考，不再作为默认验收路径。

生成时间：2026-06-07

## 1. 体验范围

- **时长：** 20–30 分钟（单人单次）
- **年龄：** 0–40 岁（不要求终局、不要求完整世界观）
- **目标：** 验证目标感、因果感、成就感、挫折感、重玩欲望

## 2. 必需表面

| 表面 | 最低要求 |
| --- | --- |
| 主动行动 | 练功、读书、交游、营商、游历（无事件时可选） |
| 事件选择 | 可见选项与基本 tradeoff |
| 属性反馈 | 关键属性有玩家向含义（P7 属性认知） |
| 路线/身份 | 至少 3 种早期倾向，40 岁前可见身份信号 |
| 人生摘要 | `LifeMemoryPanel` / 40 岁前后可读摘要 |
| 存档 | 本地读档可恢复流程（若测试脚本使用） |

## 3. 内容最低线

- 每种主动行动有：奖励、成本、风险、适用场景（catalog + UI 卡片）
- 至少 2 个 persona 在 P8 gate 中呈现不同路线/摘要
- 无阻断性 console 错误（启动、行动、选择、摘要）

## 4. 明确非目标

- 完整天赋/道具/背包经济
- 完整世界地图与终局多路线
- 完整 P6B 后端依赖（本地 Web 切片优先）
- 自动化替代真人可玩性最终判断

## 5. 准入线

- `npm run gate:playability` 无 blocker
- 浏览器验收清单通过（见 `p8-browser-acceptance-notes.md`）
- 真人测试脚本就绪（见 `p8-human-test-script.md`）

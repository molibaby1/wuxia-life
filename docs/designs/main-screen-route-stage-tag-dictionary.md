# 主界面路线与阶段标签字典

## 目标

统一主界面顶部状态条中的路线标签与阶段标签命名、展示顺序、裁剪规则与使用边界，避免不同页面、不同实现分支对同类身份信息使用不同说法。

适用范围：

- 主界面顶部状态条
- 主界面人生摘要中的路线结论
- 与主界面直接相关的阶段/身份标签展示

## 标签分层

顶部标签分为两类：

1. 路线标签
2. 阶段标签

规则：

- 首页默认最多展示 `2` 个标签
- 优先顺序：`路线标签 > 阶段标签`
- 不允许同层出现 3 个以上标签挤占顶部空间

## 1. 路线标签

路线标签用于回答：`这个角色当前主要走在哪条人生/江湖路径上`

### `neutral_route`

- 中文展示名：`中立门派`
- 语义：尚未明显偏向正、邪、官、商等极端路径
- 适用场景：角色仍处于模糊或中性发展阶段

### `orthodox_route`

- 中文展示名：`正道路线`
- 语义：明显走向守序、正统、讲求名分的成长路径

### `unorthodox_route`

- 中文展示名：`偏锋路线`
- 语义：明显偏离传统正统逻辑，行事更灵活或危险

### `merchant_route`

- 中文展示名：`营生路线`
- 语义：以谋生、财富、经营与资源积累为主要导向

### `wandering_route`

- 中文展示名：`江湖游历`
- 语义：强调游历、见闻、人际与江湖经历的开放型路径

### `scholar_route`

- 中文展示名：`读书路线`
- 语义：强调学识、谋略、科举或文修发展

## 2. 阶段标签

阶段标签用于回答：`这个角色现在处于哪一成长/身份阶段`

### `uninitiated_stage`

- 中文展示名：`未入门`
- 语义：尚未正式进入某一体系、门派或职业核心阶段

### `entry_stage`

- 中文展示名：`初入门`
- 语义：已经进入体系，但仍处于最初级阶段

### `outer_disciple_stage`

- 中文展示名：`外门阶段`
- 语义：已进入门派结构，但尚未接触核心资源

### `inner_disciple_stage`

- 中文展示名：`内门阶段`
- 语义：已进入更核心的成长与资源层

### `traveling_stage`

- 中文展示名：`游历中`
- 语义：当前阶段以行走江湖和经历事件为主

### `recovery_stage`

- 中文展示名：`调养中`
- 语义：当前阶段重点不在推进，而在恢复、休养、保全

### `survival_stage`

- 中文展示名：`求生阶段`
- 语义：当前阶段资源、身体或局势紧张，以活下去为首要目标

## 3. 顶部展示规则

推荐格式：

```text
[路线标签] [阶段标签]
```

示例：

- `[中立门派] [未入门]`
- `[江湖游历] [游历中]`
- `[营生路线] [调养中]`

规则：

- 优先展示 1 个路线标签 + 1 个阶段标签
- 如果没有稳定路线，只显示阶段标签
- 如果路线已非常明确但阶段信息价值较低，可只显示路线标签

## 4. 标签裁剪优先级

当标签数量超出首页允许数量时，按以下顺序保留：

1. 当前最决定玩家判断的路线标签
2. 当前最决定玩家节奏的阶段标签
3. 其他说明性标签后移到详情层

不建议首页顶部出现：

- 3 个以上胶囊标签并列
- 路线、阵营、门派、状态全部同时展示
- 长文句式标签

## 5. 与其他字段的关系

### 与 `routeSummary`

- 顶部标签负责极简识别
- `routeSummary` 负责人生摘要中的结论表达
- 两者可复用同一语义，但展示密度不同

### 与 `riskSummary`

- 风险不是标签，不进入顶部标签组
- 风险放在人生摘要中更合适

## 6. 使用规则

- 标签必须是短词或短短语，不写成长句
- 标签应优先帮助玩家识别身份与阶段
- 不把风味修辞当成正式标签
- 新增标签应先归类到路线或阶段，再决定是否允许进入首页顶部

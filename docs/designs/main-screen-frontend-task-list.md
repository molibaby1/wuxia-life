# 主界面前端开发任务单

## 目标

将当前主界面改造成适合 H5 与小程序的紧凑型移动端首页，满足以下结果：

1. `继续` 按钮首屏可见
2. 首页默认态不再出现重复属性
3. 属性说明退出首页，进入二级层
4. 玩家进入页面后可快速理解当前事件、风险状态与核心数值

## 范围

仅修改主界面布局、信息层级、默认展示规则与属性详情展开方式。

不包含：

- 其他页面视觉改版
- 新属性系统设计
- 数值平衡调整
- 存档逻辑与业务接口改造

## 开发任务拆分

### Task 1: 删除首页重复属性区

目标：

- 移除当前页面下半段重复展示的精简属性区
- 保证首页默认态中同一属性仅出现一次

实施要点：

- 保留一个统一的核心属性摘要区
- 删除白底重复属性区及其相关样式、渲染分支
- 检查是否有依赖该区块的锚点、滚动或测试用例

完成标准：

- 首页默认态不再出现第二套功力/外功/内功/轻功/体魄/银两

### Task 2: 上移当前事件卡与继续按钮

目标：

- 将事件内容提升为首页视觉中心
- 保证 `继续` 按钮在首屏完整可见

实施要点：

- 将事件卡放置于顶部状态条之后
- `继续` 作为唯一主按钮放在事件卡内部
- 事件正文限制为最多 3 行，超出折叠

完成标准：

- 基准移动端视口下，进入页面无需下滑即可看到完整 `继续` 按钮

### Task 3: 压缩顶部状态条

目标：

- 降低顶部区域占高
- 保留关键身份与资源信息

实施要点：

- 顶部仅保留姓名、年龄日期、门派/阶段标签、3 个高频资源、保存按钮
- 删除大面积装饰性头部空间
- 控制顶部状态条总高度在设计规范范围内

完成标准：

- 顶部区域不再挤占主内容首屏空间

### Task 4: 重构人生摘要卡

目标：

- 将松散说明区改为结论型状态卡

实施要点：

- 固定展示 3 行：路线、风险、倾向
- 文案改为短句，不再使用松散说明段落
- 风险信息允许轻强调，但不得高于主按钮

完成标准：

- 玩家进入页面后可快速读取当前路线、风险和成长倾向

### Task 5: 新建核心属性摘要卡

目标：

- 首页仅展示最关键的 6 个属性摘要

实施要点：

- 使用 `2 x 3` 栅格布局
- 每个格子只保留名称和当前值
- 移除解释句、进度条与风味文案
- 增加 `查看完整属性说明` 入口

完成标准：

- 首页属性区密度明显下降，但核心状态仍可快速扫读

### Task 6: 将详细属性迁入抽屉或折叠区

目标：

- 详细属性不再阻塞首页主循环

实施要点：

- 新增 `完整属性` 二级层
- 分组展示为：战斗 / 江湖 / 成长 / 资源
- 每项属性仅保留一条说明
- 进度条仅在详情层展示

完成标准：

- 首页默认态不再出现长属性说明
- 点击 `全部属性` 或 `查看完整属性说明` 可进入详情层

### Task 7: 统一按钮层级

目标：

- 明确页面唯一主操作

实施要点：

- `继续` 设为唯一主按钮
- `人生摘要`、`全部属性` 设为次按钮
- `保存`、页签等改为弱按钮

完成标准：

- 页面不存在多个同权重按钮互相竞争注意力

### Task 8: 响应式与安全区收口

目标：

- 保证 H5 与小程序环境下都能稳定展示

实施要点：

- 校验常见窄屏高度下首屏可见性
- 检查顶部安全区与底部安全区
- 检查按钮热区不小于 `36~40`
- 检查长文案、长标签、极端数值时的溢出表现

完成标准：

- 小程序与 H5 下首页结构不崩、按钮不被遮挡、首屏主流程不丢失

## 推荐实施顺序

1. Task 1 删除重复属性区
2. Task 2 上移事件卡与继续按钮
3. Task 3 压缩顶部状态条
4. Task 4 重构人生摘要卡
5. Task 5 新建核心属性摘要卡
6. Task 6 新建完整属性详情层
7. Task 7 统一按钮层级
8. Task 8 响应式与安全区收口

## 验收清单

- 首页首屏完整可见 `继续`
- 默认态无重复属性
- 默认态不出现属性百科式说明
- 玩家能快速看到当前事件、风险与核心属性
- `全部属性` 可进入详情层
- H5 与小程序下点击区域、布局与安全区表现正常

## 建议的组件拆分

- `TopStatusBar`
- `CurrentEventCard`
- `LifeSummaryCard`
- `CoreStatsGrid`
- `FullStatsDrawer`
- `StatsTabSection`
- `PrimaryActionButton`
- `SecondaryActionRow`

## 建议的数据结构调整

- 将首页摘要数据与完整属性数据拆分为两个展示层
- 保持底层数据源可复用，但渲染逻辑分离
- 首页摘要层禁止直接复用完整属性长说明组件

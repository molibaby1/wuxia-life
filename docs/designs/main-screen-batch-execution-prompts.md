# 主界面改版执行 Prompts

## 用法

以下内容用于分发给其他会话或工程师执行主界面改版任务。

每个 Prompt 都有明确范围、非目标、验收标准与参考文档，避免执行时扩散范围。

推荐使用方式：

1. 每次只派发一个 Batch
2. 执行前先阅读对应参考文档
3. 完成后按验收标准回报结果

---

## Batch 1 执行 Prompt

你现在负责 `wuxia-life` 主界面改版的 `Batch 1: 首屏主流程重构`。

### 目标

解决当前主界面最严重的问题：

- `继续` 按钮无法首屏直达
- 当前事件卡位置过低
- 首页存在重复属性区
- 顶部区域占高过大

### 必读文档

- `docs/designs/main-screen-ui-spec.md`
- `docs/designs/main-screen-frontend-task-list.md`
- `docs/designs/main-screen-implementation-batches.md`

### 本批次范围

只做以下内容：

1. 删除首页重复属性区
2. 上移当前事件卡与 `继续` 按钮
3. 压缩顶部状态条

### 非目标

不要做以下内容：

- 不改其他页面
- 不新增新玩法或新字段
- 不处理属性详情抽屉
- 不重写完整属性文案
- 不做额外视觉美化扩散

### 实施要求

- 保持数据语义不变，优先调整布局与展示顺序
- `继续` 必须成为页面唯一主按钮
- 基准移动端视口下，进入页面无需滚动即可看到完整 `继续`
- 删除首页白底重复属性区
- 顶部状态条只保留高频信息

### 验收标准

完成后必须确认：

1. 首页默认态不再出现第二套重复属性
2. 当前事件卡位于顶部状态条之后
3. `继续` 在首屏完整可见
4. 顶部区域明显压缩，不再挤占主内容

### 输出要求

完成后请返回：

1. 改动了哪些组件或文件
2. 首屏结构变更说明
3. 验证结果
4. 仍未解决的边界问题

## Batch 2 执行 Prompt

你现在负责 `wuxia-life` 主界面改版的 `Batch 2: 信息层级与摘要重构`。

### 目标

在首屏主流程理顺后，将首页默认态改成摘要优先，而不是属性百科优先。

### 必读文档

- `docs/designs/main-screen-ui-spec.md`
- `docs/designs/main-screen-frontend-task-list.md`
- `docs/designs/main-screen-implementation-batches.md`

### 本批次范围

只做以下内容：

1. 重构人生摘要卡
2. 新建核心属性摘要卡
3. 统一按钮层级

### 非目标

不要做以下内容：

- 不处理 Batch 1 的结构性问题
- 不新增完整属性抽屉
- 不扩散到别的页面
- 不改业务逻辑和数值逻辑

### 实施要求

- 人生摘要固定为三条结论信息：路线、风险、倾向
- 核心属性区使用 `2 x 3` 栅格
- 首页属性只显示名称和值
- 首页默认态不得出现进度条、长解释和风味句
- `继续` 仍然是唯一主按钮
- `人生摘要`、`全部属性` 只能是次按钮

### 验收标准

完成后必须确认：

1. 首页可快速读到路线、风险、倾向
2. 核心属性区仅保留 6 个关键属性摘要
3. 首页默认态不再出现属性解释句与风味文案
4. 页面按钮权重清晰，没有多个主按钮竞争

### 输出要求

完成后请返回：

1. 新增或重构了哪些组件
2. 首页摘要层的最终结构
3. 文案和按钮层级调整说明
4. 验证结果

## Batch 3 执行 Prompt

你现在负责 `wuxia-life` 主界面改版的 `Batch 3: 属性详情层与适配收口`。

### 目标

将完整属性信息迁入二级层，并完成 H5 / 小程序环境下的适配收口。

### 必读文档

- `docs/designs/main-screen-ui-spec.md`
- `docs/designs/main-screen-frontend-task-list.md`
- `docs/designs/main-screen-implementation-batches.md`

### 本批次范围

只做以下内容：

1. 新建完整属性抽屉或折叠区
2. 将详细属性说明迁入二级层
3. 完成响应式与安全区收口

### 非目标

不要做以下内容：

- 不回头重构 Batch 1 和 Batch 2 已确认结构
- 不新增其他页面的抽屉组件改版
- 不修改属性含义与业务规则

### 实施要求

- 完整属性层按 `战斗 / 江湖 / 成长 / 资源` 分组
- 首页默认态不再展示长属性说明
- 点击 `全部属性` 或 `查看完整属性说明` 能进入详情层
- 检查 H5 与小程序的顶部安全区、底部安全区、窄屏高度、长标签、长文案、极端数值

### 验收标准

完成后必须确认：

1. 首页与详情层职责分离明确
2. 完整属性入口可正常工作
3. 小程序与 H5 下页面结构不崩
4. 主按钮与关键卡片未被安全区遮挡

### 输出要求

完成后请返回：

1. 完整属性层采用了什么结构
2. 属性分组与交互方式说明
3. 适配验证结果
4. 仍存在的风险项

## 总控 Prompt

如果你希望单个会话完整负责主界面改版，可使用以下总控 Prompt：

你现在负责 `wuxia-life` 主界面改版，请严格按以下文档执行：

- `docs/designs/main-screen-ui-spec.md`
- `docs/designs/main-screen-frontend-task-list.md`
- `docs/designs/main-screen-implementation-batches.md`

请严格按三个批次顺序推进：

1. Batch 1: 首屏主流程重构
2. Batch 2: 信息层级与摘要重构
3. Batch 3: 属性详情层与适配收口

要求：

- 不扩散到其他页面
- 不新增玩法
- 不修改业务语义
- 每完成一个批次先自检，再进入下一批次
- 输出内容必须包含：改动文件、结构变化、验收结果、残余风险

主目标只有一个：

让玩家进入主界面后，能在 3 秒内看懂当前事件、风险状态和下一步操作，并且 `继续` 按钮在首屏稳定可见。

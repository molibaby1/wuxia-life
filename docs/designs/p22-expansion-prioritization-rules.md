# P22 Expansion Prioritization Rules (US-004)

## High-Value Gap Priority

1. **Weak archetype bands first** — wealth merchant, hermit withdrawal, frontier/streetborn origins (per P20 audit).
2. **Stage bridges second** — events that connect early flags to mid/late consequence (mentor obligation, sect duty).
3. **Closure differentiation third** — endgame and historical-memory tones for non-martial runs.

## Redundancy vs Harmful Thinness

| Signal | Acceptable | Harmful |
|--------|------------|---------|
| Same thematic class across routes | setback/echo callbacks with distinct stage signals | identical text/effects on unlike routes |
| Pool size | ≥ baseline minimumEventCount per pool | < 50% minimum without wave plan |
| Title clustering | < 30% overlap within pool | ≥ 70% title-prefix overlap (repetitive) |

## Deferred Beyond P22

- New route families or UI surfaces
- Full explorer-wanderer archetype family (P20 gap — document only)
- LLM-automated bulk generation without human review gate
- Cross-theme (non-wuxia) content pools

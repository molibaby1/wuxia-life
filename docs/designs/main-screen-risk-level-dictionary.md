# 主界面风险等级字典

## 目标

统一主界面中 `风险` 字段的等级命名、展示文案、触发语义与使用边界，避免不同页面、不同事件、不同实现分支对风险状态各自表述。

适用范围：

- 主界面人生摘要卡中的 `风险`
- 当前事件后的状态反馈
- 与主界面紧密相关的提示、标签与结论型摘要

不适用范围：

- 战斗内实时伤害数值提示
- 复杂后台规则评分
- 需要完整公式解释的系统内部调试输出

## 设计原则

- 风险字段服务于玩家判断，不服务于系统炫技
- 首页风险必须是结论，不是分析过程
- 风险等级数量保持克制，便于快速扫读
- 同一级风险在不同页面的语气、颜色、权重应保持一致

## 风险字段结构

推荐使用以下结构：

```ts
type RiskSummary = {
  level: "safe" | "low" | "medium" | "high" | "critical";
  label: string;
  shortText: string;
  source?: string;
};
```

说明：

- `level`：内部等级键
- `label`：对外展示等级名
- `shortText`：首页结论型短句
- `source`：可选，标识主要风险来源，仅用于内部整理或详情层，不要求首页展示

## 风险等级定义

### 1. `safe`

- 中文展示名：`稳`
- 语义：当前没有需要特别干预的明显风险，状态基本平稳
- 首页展示建议：
  - `稳 · 暂无明显隐患`
  - `稳 · 当前状态平稳`
- 使用边界：
  - 不代表角色强，只代表当前无需立即处理风险
  - 不用于夸张正面评价

### 2. `low`

- 中文展示名：`低`
- 语义：存在轻微风险，但暂不影响主循环推进
- 首页展示建议：
  - `低 · 略有隐忧`
  - `低 · 尚可应付`
- 使用边界：
  - 适用于轻伤、轻度资源紧张、轻微关系波动等
  - 不应用于已经显著影响选择空间的状态

### 3. `medium`

- 中文展示名：`中`
- 语义：风险已经值得玩家关注，可能影响后续事件结果或成长节奏
- 首页展示建议：
  - `中 · 身子正虚`
  - `中 · 银钱略紧`
  - `中 · 门内处境不稳`
- 使用边界：
  - 是首页最常见的“提醒型风险”
  - 应提示玩家关注，但不等于立即失败

### 4. `high`

- 中文展示名：`高`
- 语义：风险明显，若继续放任，很可能引发负面后果或锁死部分机会
- 首页展示建议：
  - `高 · 伤势未愈`
  - `高 · 囊中见底`
  - `高 · 风评急转`
- 使用边界：
  - 用于已经开始压缩玩家选择空间的状态
  - 应搭配较明显的视觉提醒，但仍低于系统级报错感

### 5. `critical`

- 中文展示名：`危`
- 语义：风险已到临界状态，玩家应优先处理，否则极可能触发严重后果
- 首页展示建议：
  - `危 · 命数堪忧`
  - `危 · 断粮在即`
  - `危 · 四面树敌`
- 使用边界：
  - 只用于真正需要立即处理的状态
  - 不能滥用，否则会削弱风险系统可信度

## 首页展示规范

首页风险统一使用以下格式：

```text
风险：{等级} · {短句}
```

示例：

- `风险：稳 · 暂无明显隐患`
- `风险：低 · 略有隐忧`
- `风险：中 · 身子正虚`
- `风险：高 · 囊中见底`
- `风险：危 · 命数堪忧`

规则：

- 首页只展示一个主风险结论
- 不同时并列多个风险句
- 如果存在多个风险源，应取当前最影响玩家决策的那一个

## 风险短句规范

首页风险短句必须满足：

- 长度尽量控制在 `4~8` 字
- 优先结论式表达
- 不能写成系统说明书
- 不能同时塞入多个因果关系

推荐写法：

- `身子正虚`
- `银钱吃紧`
- `门内不稳`
- `风评受损`
- `后劲不足`

不推荐写法：

- `由于前序事件受伤所以近期身体状态下降`
- `当前财富较低可能影响部分商业与购买选项`
- `你似乎在一些人眼中留下了不好的印象`

## 风险来源优先级建议

当多个风险同时存在时，首页风险建议按以下优先级选取：

1. 生存类风险
2. 主线推进阻塞风险
3. 身份/门派地位风险
4. 资源断裂风险
5. 人际与风评风险
6. 一般成长节奏风险

说明：

- 优先展示最可能改变玩家下一步选择的风险
- 不优先展示“系统认为重要但玩家当前不会因此改决策”的风险

## 风险等级与视觉权重映射

建议映射如下：

| level | 中文 | 视觉建议 |
| --- | --- | --- |
| `safe` | 稳 | 中性灰褐或低强调色 |
| `low` | 低 | 轻暖色或弱提示色 |
| `medium` | 中 | 赭黄或中等提醒色 |
| `high` | 高 | 深赭或偏警示色 |
| `critical` | 危 | 最重风险色，但仍需保持产品内一致性 |

规则：

- 风险色只在风险字段局部使用
- 不要让整张卡片都变成告警色
- 风险权重不得高过 `继续` 的点击识别性

## 与其他字段的关系

### 与 `routeSummary`

- `routeSummary` 负责说明角色当前方向
- `riskSummary` 负责说明当前最需要注意的问题
- 两者不能混写为一句

### 与 `tendencySummary`

- `tendencySummary` 负责说明成长偏向
- `riskSummary` 不负责解释成长路径

### 与当前事件正文

- 当前事件正文回答“发生了什么”
- 风险回答“这件事最需要你警惕什么”
- 两者角色不同，不能互相替代

## 使用规则

- 首页默认态只能有一个主风险字段
- 详情层可以补充更多风险来源，但首页不展开
- 不要把临时情绪、风味修辞直接当成风险等级
- 风险字段必须能帮助玩家做下一步判断

## 建议的后续扩展

如果后续要继续完善主界面状态系统，建议补：

1. `路线标签字典`
2. `成长倾向生成规则`
3. `风险来源归类表`

这样可以进一步统一：

- 首页摘要生成逻辑
- 风险文案来源
- 多系统状态收敛方式

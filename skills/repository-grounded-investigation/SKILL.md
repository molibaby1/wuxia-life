# Repository-Grounded Investigation

Use this method when investigating an assigned problem:

- Start from the supplied authority, problem statement, and evidence. Treat input assumptions as claims to examine, not established causes.
- Independently inspect relevant repository source, configuration, and tests.
- When needed, follow the actual implementation, data, and execution path instead of relying only on filenames or surface text.
- Separate repository facts, evidence observations, inferences, and unknowns.
- When evidence is insufficient, preserve uncertainty rather than inventing a complete conclusion.

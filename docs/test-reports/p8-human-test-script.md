# P8 Human Test Script and Observation Sheet

生成时间：2026-06-07

## A. 测前说明（给玩家，约 1 分钟）

- 这是一款武侠人生模拟，从零岁开始做选择、安排生活。
- 请按直觉游玩，**不要**查攻略或外部说明。
- 目标不是「通关」，而是体验前四十年的人生节奏。
- 测试约 **20–30 分钟**，到 40 岁左右或主持人叫停即可。

## B. 玩家流程（5–8 人，各 20–30 分钟）

1. 新游戏 → 自选或随机姓名性别
2. 遇到**无事件**时尝试不同**主动行动**（练功/读书/交游/营商/游历）
3. 遇到**选择事件**时按真实偏好选
4. 打开**属性**与**人生记忆**面板至少各 1 次
5. 玩到约 **40 岁**（或主持人提示结束）
6. 填写测后问卷（下方）

## C. 测后问卷（玩家）

1. 你有没有形成「这局想做什么」的目标？（1–5）
2. 早期选择/backend 结果，后面是否感觉到呼应？（1–5）
3. 有没有完成一件你觉得「值得」的事？举例。
4. 挫折/负面结果是否公平、可理解？（1–5）
5. 若再开一局，你会换做法吗？为什么？
6. 能否用一句话讲出这局故事？

## D. 观察者清单

| 信号 | 记录 |
| --- | --- |
| 困惑（属性/行动/选项看不懂） | Y/N + 时刻 |
| 犹豫（>30s 不知选什么） | Y/N + 时刻 |
| 无聊（空窗、重复感） | Y/N + 时刻 |
| 重启意图（「想重开」口头表达） | Y/N |
| Console 错误 | 复制消息 |
| 阻断性 bug | 描述 |

## E. 样本量

- 5–8 名玩家，男女/经验混合
- 每人独立 seed，不互相观看
